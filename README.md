# skwod releases

Signed builds of the skwod apps and their update feeds. Nothing here is a server; skwod is self-hosted and decentralized.

- **Mac:** download the latest `.dmg`/`.zip` below. The app updates itself (Sparkle, EdDSA-signed).
- **Android:** download the latest `.apk`. The app checks for signed updates.
- **iPhone:** via TestFlight.

Every update is signed with the publisher key; the apps refuse anything else.
